# 030 Map

## Overview

A full-screen map the player toggles with the Select action (Tab on the keyboard, Back on a controller). It works like Hollow Knight's map: the game is not paused, enemies and physics keep running, and the player can still walk while looking at it, only more slowly. This is an MVP: the map is a simple baked image of the level's tiles plus a player marker.

## Behavior rules

- Pressing Select toggles the map open and closed. Key remapping keeps working through `Settings` (the action is labelled "Map").
- Opening the map never pauses the tree.
- While the map is open, the player's horizontal top speed is multiplied by `move_speed_multiplier` (default 0.4). Jumping, spells and dashing are unchanged.
- Closing the map restores the normal speed. Equipment and stats keep owning `max_speed`; the map only sets `HorizontalMovementComponent.speed_multiplier`.
- The map ignores Select while the game is paused (pause menu open).
- The map image is built once, on first open, from the cells of the assigned tile layers (one pixel per tile). The player marker follows the player every frame while open.

## Scene composition

| Node | Owner | Role |
| --- | --- | --- |
| `Main/MapLayer` (CanvasLayer, layer 5) | `Main.tscn` | Draws above the HUD and dialogue, below the pause menu (10) and death screen (50). |
| `MapLayer/MapOverlay` | `map/MapOverlay.tscn` | Input, open/close state, slow-walk, drawing. |

## Public contracts

- `MapOverlay.open()`, `close()`, `toggle()`, `is_open()`; signals `opened`, `closed`.
- `MapOverlay.world_to_map(world_position)` converts world coordinates to map coordinates.
- `HorizontalMovementComponent.speed_multiplier` (runtime, default 1.0).

## Failure handling

- Missing `player` or `horizontal_movement` reports a configuration error; the map still toggles but cannot slow the player.
- Tile layers without tiles produce a warning and an empty map.

## Scope limits

No fog of war, rooms, map pins, zoom or panning. The final art will replace the baked tile image.

## Acceptance criteria

Covered by `tests/map/`: Select opens and closes the map, the game is not paused, the player keeps moving at the slowed speed, closing restores the speed, and paused input is ignored.
